# e-plantShopping

## Paradise Nursery

A React-based online plant shopping application built with React,
Redux Toolkit, and React Router.

## Features

- Paradise Nursery landing page
- Get Started button
- Plant product listing
- Multiple plant categories
- Plant images, names, and prices
- Add to Cart functionality
- Redux Toolkit cart management
- Increase and decrease quantity
- Direct quantity updates
- Remove items from cart
- Dynamic cart item count
- Dynamic cart total
- About Us page
- Home, Plants, About, and Cart navigation
- Responsive design
- Landing page background image

## Technologies

- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- CSS
